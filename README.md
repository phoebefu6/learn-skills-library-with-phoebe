# Learn Your Own Skills Library with Phoebe

Six 45-minute sessions on running your own library of AI assistant skills: when repeated work deserves
a skill, descriptions an assistant can find, one well-built skill, a routing bench in the browser,
testing skills like code, and the upkeep a growing library needs. By Phoebe Fu.

- `index.html` - the landing page and knowledge map
- `courses/01..06` - the sessions; session 4 is the skill-routing bench
- `assets/skl-live.js` - the bench: a BM25 keyword router (a labelled stand-in for the language model a
  real assistant uses) over a constructed library; `assets/skl-sample.js` - its data, generated by
  `materials/build_skl_sample.py` with `json.dumps`
- `materials/skl_reference.py` - a Python twin of the router; `materials/compare-ladder.py` checks it
  against `node materials/skl-node.js` by value (`--plant` must fail)

Pemberton & Thistle, its clients, its skills library and every bench request are constructed for
teaching. Vendor facts were read at source on 2026-11-25 and change often: re-check before relying on them.
